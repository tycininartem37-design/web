# Страница «О себе» — вариант 2

Одностраничный сайт Артема Тычинина на тему «Путешественник».

## Содержимое

- семантические теги `header`, `main`, `section`, `aside`, `footer`;
- навыки, полезные в путешествиях;
- список посещённых стран;
- любимое место — Грузия;
- изображение с атрибутами `src`, `alt`, `width`, `height`;

Откройте `index.html` в браузере для просмотра страницы.
